Contractions

à + le = au

  • Je vais au cinéma.
  • 这里，à 是介词表示方向或位置，而 le 是阳性单数定冠词。

à + les = aux

  • Je parle aux enfants.
  • 这里，à 表示方向或位置，而 les 是复数定冠词。

de + le = du

  • Il vient du marché.
  • 这里，de 表示来源，而 le 是阳性单数定冠词。

de + les = des

  • C'est la maison des voisins.
  • 这里，de 表示所属，而 les 是复数定冠词。

Verb Groups

Traditional Classification

  • 法语里面，动词类型分为 3 组：第一组、第二组、第三组。
  • 第一组动词和第二组动词变位规律。
  • 第三组动词变位不规律。
  • Premier groupe
  • Deuxième groupe
  • Troisième groupe

Present Tense

First Group Rules

  • ils / elles 对应的动词变位，ent 不发音。
  • 去掉 er 之后加上：
    • je: -e
    • tu: -es
    • il / elle / on: -e
    • nous: -ons
    • vous: -ez
    • ils / elles: -ent
  • 例如：parler
    • je parle
    • tu parles
    • il / elle parle
    • nous parlons
    • vous parlez
    • ils / elles parlent

Special First Group Changes

  • -ger 结尾：nous -geons
  • -cer 结尾：nous -çons
  • 例如：lancer
    • je lance
    • tu lances
    • il lance
    • nous lançons
    • vous lancez
    • ils lancent
  • 例如：changer
    • je change
    • tu changes
    • il change
    • nous changeons
    • vous changez
    • ils changent

é -> è

  • 倒数第二个音节元音为 é 的单词，在 je / tu / il-elle / ils-elles 变位时，将倒数第二个音节的 é 变为 è。
  • 例如：répéter
    • je répète
    • tu répètes
    • il répète
    • nous répétons
    • vous répétez
    • ils répètent

y -> i

  • 以 oyer, uyer 结尾的单词，在 je / tu / il-elle / ils-elles 变位时，将 y 变为 i。
  • ayer 结尾的动词既可以变 i，也可以保留 y。
  • 例如：essuyer
    • j’essuie
    • tu essuies
    • il essuie
    • nous essuyons
    • vous essuyez
    • ils essuient

e -> è

  • 倒数第二个音节中元音音素只有 e 并且 e 发 [ə] 或不发音时，在 je / tu / il-elle / ils-elles 变位时，将 e 变为 è。
  • 例如：acheter
    • j’achète
    • tu achètes
    • il / elle achète
    • nous achetons
    • vous achetez
    • ils / elles achètent
  • 例如：lever
    • je lève
    • tu lèves
    • il lève
    • nous levons
    • vous levez
    • ils lèvent

Double Consonants

  • 大部分以 eler 或 eter 结尾的单词，在动词变位时双写辅音，而不是将 e 变为 è。
  • 例如：appeler
    • j’appelle
    • tu appelles
    • il / elle appelle
    • nous appelons
    • vous appelez
    • ils / elles appellent
  • 例如：jeter
    • je jette
    • tu jettes
    • il jette
    • nous jetons
    • vous jetez
    • ils jettent

Second Group Rules

  • 直陈式现在时：去掉 ir 加相应词尾
    • je -is
    • tu -is
    • il / elle / on -it
    • nous -issons
    • vous -issez
    • ils / elles -issent
  • 例如：finir
    • je finis
    • tu finis
    • il / elle / on finit
    • nous finissons
    • vous finissez
    • ils / elles finissent
