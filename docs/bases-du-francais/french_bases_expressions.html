Birth

Je suis né/née en + année

  • Je suis né/née en + 年份。
  • 我出生在 xxxx 年。
  • Je suis né en + 年份（男）
  • Je suis née en + 年份（女）

Je suis né/née le ...

  • 我出生在 xxx（日月年）
  • Je suis né/née le (21 décembre 1971)
  • Je suis né le vingt et un décembre mille neuf cent soixante et onze.

Personal Info

Mon numéro de téléphone est ...

  • 我的电话号码是：
  • Mon numéro de téléphone est le + 电话号码

C'est quoi ?

  • cest quoi - what is

J'ai ... ans

  • J'ai xxx ans.

J'habite ...

  • 我住在 xxx 号，xxx 街。
  • J'habite au (街号55), rue (Sainte-Catherine街名)
  • J'habite au 55, rue Sainte-Catherine, (如果有公寓号，例如 appartement 15.)
  • J’habite au 55, rue Sainte-Catherine, appartement 15, à Montréal, au Québec, au Canada.

Mon code postal est ...

  • 我的邮政编码是 H2X 1Y4
  • Mon code postal est H2X 1Y4.

Je m’appelle ... Enchantée !

  • 我叫 xxx，幸会！
  • Je m’appelle xxx. Enchantée !（女）

Date And Time

Nous sommes ...

  • 今天是 8 月 23 号周五。
  • Nous sommes + 星期，le 日 月
  • Nous sommes = we are
  • Nous sommes vendredi, le vingt-trois août

Il est ...

  • 现在是 7 点 42 分。
  • Il est 7 heures 42.
  • 报时间：24 小时制！！！
  • 早上 6 点：6 heures du matin
  • 中午 3 点：3 heures de l'après-midi
  • 晚上 9 点：9 heures du soir

Money

Je dois payer ...

  • 我应该支付 12 刀 50 分，对吧？
  • Je dois payer 12 dollars 50 sous, c'est bien ça ?
  • Vous devez payer ... 您应该支付……

Restaurant

Une table pour deux

  • 您好，请给我们一张两人桌。
  • Bonjour, une table pour deux, s’il vous plaît.
  • 我们两位
  • Nous sommes deux = On est deux（口语）
