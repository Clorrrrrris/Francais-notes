Present Tense Conjugations

1. manger 吃

  • je mange
  • tu manges
  • il / elle mange
  • nous mangeons
  • vous mangez
  • ils / elles mangent

2. changer 改变

  • je change
  • tu changes
  • il / elle change
  • nous changeons
  • vous changez
  • ils / elles changent

3. commencer 开始

  • je commence
  • tu commences
  • il / elle commence
  • nous commençons
  • vous commencez
  • ils / elles commencent

4. préférer 宁愿 / 更喜欢

  • je préfère
  • tu préfères
  • il / elle préfère
  • nous préférons
  • vous préférez
  • ils / elles préfèrent

5. compléter 补全 / 填满

  • je complète
  • tu complètes
  • il / elle complète
  • nous complétons
  • vous complétez
  • ils / elles complètent

6. répéter 重复

  • je répète
  • tu répètes
  • il / elle répète
  • nous répétons
  • vous répétez
  • ils / elles répètent

7. acheter 购买

  • j’achète
  • tu achètes
  • il / elle achète

  • vous achetez
  • ils / elles achètent

8. envoyer 派遣

  • j’envoie
  • tu envoies
  • il / elle envoie
  • nous envoyons
  • vous envoyez
  • ils / elles envoient

9. payer 支付

  • 两种形式都正确，通常推荐第一种。
  • je paie (ou paye)
  • tu paies (ou payes)
  • il / elle paie (ou paye)
  • nous payons
  • vous payez
  • ils / elles paient (ou payent)
